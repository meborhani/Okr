# OKR Frontend

## اجرا

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## env

```env
VITE_API_BASE_URL=http://localhost:3000/api/v1
```

## مسیرها

| مسیر | صفحه |
|------|------|
| `/login` | ورود |
| `/dashboard` | داشبورد |
| `/my-okrs` | اهداف من |
| `/objectives` | همه اهداف |
| `/objectives/new` | هدف جدید |
| `/objectives/:id` | جزئیات هدف |
| `/key-results/new` | KR جدید |
| `/key-results/:id` | جزئیات KR |
| `/check-in` | ثبت چک‌این |
| `/periods` | دوره‌ها |
| `/reports` | گزارش‌ها |
